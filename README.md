# DEADFRONT // Apex Cyber Protocol

Fast-paced 3D sci-fi survival shooter featuring procedural high-resolution animated mechs, tiered waves, buyable arsenal, tactical power-ups, and rogue-lite progression.

## Setup & Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Open your browser at:
   `http://localhost:3000`

## Controls
- **W, A, S, D**: Directional Movement
- **Mouse**: Aim Reticle
- **Left Click**: Fire Weapon
- **Shift / Space**: Thruster Dash / High Jump
- **R**: Reload Magazine
- **1 - 6**: Quick Weapon Switch
- **B**: Open Tactical Armory Shop
- **P / Esc**: Pause Simulation
