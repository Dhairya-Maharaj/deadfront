# DEADFRONT — Outlast the Dark

An original browser-based 3D survival FPS prototype. The game code in this project is written for DEADFRONT and is not copied from another repository.

## Play locally
Open `index.html` in a modern browser while connected to the internet (Three.js is loaded from jsDelivr CDN). For best results, use a local static server such as VS Code Live Server.

## GitHub Pages
1. Put `index.html`, `manifest.json`, and this README in the root of your repository.
2. In GitHub, open Settings → Pages.
3. Set the source to Deploy from a branch, select `main` and `/(root)`, then Save.
4. Wait for deployment and open `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

No build step is required.

## Controls
- Desktop: WASD / arrows move, mouse aims, left click fires, Space jumps, Shift sprints, Q dashes, R reloads, 1–4 switch weapons, Esc pauses.
- Touch: left joystick moves, drag on the right side to aim; Fire, Jump, Dash, Reload, and Swap buttons are provided.
- Loadout selection: choose weapon and combat style before deploying.

## Gameplay
- Wave survival, four weapons (Rift, Boom, Viper, Longshot), Runner/Bulwark styles, hostile NPCs, health/armor/ammo pickups, scrap, jumping, ramps, and elevated platforms.
- This is a prototype. Test it in the target browsers/devices and tune gameplay before public release.
